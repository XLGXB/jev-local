# Controlled JSON UI Choice consumer

`jevlocal.integration.json_render_consumer` selects one **caller-supplied** static UI schema with a single local-native, uncalibrated Choice question. It does not generate JSON, HTML, CSS, scripts, URLs, or actions. The selected schema is the validated copy of an input variant; HTML comes solely from `json_render.render_html`. A `defer` result has no UI or preview. All original candidates remain in `input.json`.

## Input and API

Input is UTF-8 JSON with exactly `schema_version: 1`, `request_id`, `intent`, `data_classification: "public"`, and `variants`. Supply 1–8 variants, each with exactly `id`, `rationale`, `ui`. IDs are unique ASCII `[A-Za-z0-9_.:-]{1,128}`, excluding `defer`. Intent is at most 2,000 characters; rationale at most 500; the complete normalized request is at most 64 KiB. All UIs pass the strict catalog validator before a model is built or called. Duplicate JSON keys, nonfinite values, unknown keys, controls, and recognizable secrets are rejected. The shared lexical sanitizer is **best-effort secret screening, not proof of public/private classification**. Callers must supply public material only.

Library API: `validate_selection_request(request) -> copied_dict`; `pack_state(request) -> dict`; `unpack_state(state, request_id) -> copied_dict`; `select_ui(request, predictor) -> dict`. The latter accepts only an uncalibrated native Laya/Kev predictor with a 64-hex runtime fingerprint. It calls `predict` once with one Choice question. Its `state` contains the full validated intent and variants in reversible positional encoding. `state.encoding_version` is 1; its documented decoding rule fixes the request and every UI schema version to 1. The redundant constant is restored by decoding rather than repeated in model state. Each variant is `[id,rationale,[title,[layout kind,columns,gap],components]]`; each component is `[id,type,[props in catalog-defined order]]`. The complete field-order legend appears in the Choice instructions. Before inference, every decoded variant and the full decoded request must equal the original validated candidate data. No string, property, component, variant, or ordering information is summarized or dropped. Criteria contain each original rationale plus explicit `defer`. The selected answer must be an argmax of the complete finite normalized distribution at temperature 1. Probability is an **uncalibrated recommendation**, never a qualification or permission to act.

The 64 KiB input limit is a validation ceiling, **not** a guarantee that a native backend's smaller token budget can encode every valid input. The backend must reject capacity overflow; this consumer does not truncate input, shorten intent, remove candidates, or retry with changed semantics.

The direct library call is `network_policy: "caller_owned"`: it does not install a socket guard. The isolated CLI worker installs the guard before model import and changes this claim to `deny_socket_connect`; the parent requires that exact worker value.

## Bounded CLI

```text
python -m jevlocal.integration.json_render_consumer --input ABS --runtime ABS --output-dir ABS --timeout-seconds 120
```

`--runtime` is the exact local-native spec accepted by `native_context.validate_native_spec`. `--timeout-seconds` defaults to 120 and cannot exceed 120. Input/runtime/output paths must be absolute local paths, not UNC or reparse paths. The parent validates input and runtime *before* creating the output directory. That directory must not exist and is created exclusively. It retains `input.json`, `runtime.json`, `worker.log`, `receipt.json`; on a successful child result, `result.json`; on non-defer selection, `preview.html`. Existing output is never overwritten. A failed run preserves first failure evidence and is not retried. Exit 0 means the parent validated the child's result and reaped the child, including valid `defer`; exit 2 means refusal/failure. A defer has no preview.

The worker uses the same `sys.executable` with `-I -B` and an explicit absolute source-tree bootstrap, not cwd or inherited `PYTHONPATH`. It sets `HF_HUB_OFFLINE`, `TRANSFORMERS_OFFLINE`, `HF_HUB_DISABLE_TELEMETRY`, and `TORCH_FORCE_WEIGHTS_ONLY_LOAD` before native imports, and denies `socket.connect`, `connect_ex`, and `create_connection` in that child. No fallback, server, daemon, or persistent listener is created. Parent timeout and post-spawn failure kill and wait up to 20 seconds for the direct child; this module does **not** claim complete cleanup of every descendant process. For full process-tree protection, use the separately verified Windows Job wrapper.

The parent rechecks the closed candidate set, original UI/HTML, request hash, runtime-spec hash, catalog source fingerprint, consumer source SHA-256, runtime fingerprint shape, and complete uncalibrated reply. `receipt.json` records PID, exit/reap state, wall/timeout, source and input hashes. Child-reported success alone is insufficient. `model_calls: 1` is the library-level call count for an accepted result, not proof of semantic correctness. Native model quality and generalization require separate real-run and human/independent evaluation.
